# QRShield
Project for 24 - Hackathon

## Mobile Frontend
The mobile client is built with React Native, Expo, and TypeScript inside the [`Frontend/`](./Frontend/) directory.
See [Frontend README](./Frontend/README.md) and [Frontend Specification](./Frontend/QRShield_Frontend_Specification.md) for details.

## Chrome Extension
The desktop browser inspector is built with React, TypeScript, Vite, and Manifest V3 inside the [`Extension/`](./Extension/) directory.
See [Extension README](./Extension/README.md) for loading unpacked instructions, testing, and API configuration.
